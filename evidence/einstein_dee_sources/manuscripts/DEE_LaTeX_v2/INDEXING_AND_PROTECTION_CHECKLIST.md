# Indexing and authorship record checklist

1. Reserve a new Zenodo DOI before finalizing the PDF, then insert that DOI into `main.tex` and recompile.
2. Publish the PDF, TeX source, and supplementary CSV files as one Zenodo versioned record.
3. Add the Zenodo DOI to ORCID and LinkedIn.
4. Create a version-controlled code repository and archive a tagged release to Zenodo once the solver code is reproducible.
5. Submit the TeX source package to arXiv only after the equations, references, and source-file contents have been audited.
6. Keep each revision numbered and dated; do not overwrite earlier public records.
7. For PRD, use the APS REVTeX source and submit the compiled PDF plus source and figures.

A DOI and public timestamp establish a strong, citable record of what was disclosed and when. They do not replace peer review or independently prove scientific correctness.
