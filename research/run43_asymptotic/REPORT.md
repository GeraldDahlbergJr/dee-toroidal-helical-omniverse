# Run 43 angular asymptotics and frozen-auditor consistency

**Recommendation: investigate frozen-operator consistency**, starting with the composition of the radial differentiation rows near the inner wall. On all four audit grids, the two operators evaluated on the same refined fields give very different residuals. The frozen-minus-independent difference accounts for the dominant squared contribution to all three hybrid gate deficits. The experiment identifies an operator discrepancy in this regime. Attribution to a particular radial row, coordinate direction, or term in the tensor divergence requires a separate test.

The unchanged hybrid acceptance suite reproduced **9/12**. Its three failures are the inner-band momentum orders 0.474714, 0.881283, and 1.123133 for 8→16, 16→32, and 32→64, respectively, against $p\geq1.5$.

## Fixed-grid comparison

For each audit grid $N$, the angular sweep uses $8N$ uniform radial nodal intervals and the archived continuous quartic radial basis. The physical sources, toroidal geometry, coupling and Dirichlet wall traces are fixed. A refinement factor $k$ means $kN$ nodes per angle. The reference solves the archived equivariant equations, with azimuth represented through the rotation generator and azimuthal damping, then restricts to coincident audit nodes. The $1N$ fields come from the radial archive. The $2N$ and $4N$ fields at $8N$ radial intervals were regenerated byte for byte. The results also reproduce the 4N signed deficit decomposition in the preceding report.

The frozen residual $F_k$ uses the original order-two tensor momentum auditor on the restricted fields. The independent residual $I_k$ uses the continuum operator $\psi^{-10}\operatorname{div}L(W)-8\pi G\psi^{-4}S$. It differentiates the reference's quartic radial polynomials analytically on each adjacent element, uses the trigonometric interpolant for poloidal derivatives, and differentiates azimuthal rotations exactly. For the tensor's azimuthal derivative, the rotation generator $J$ acts as $JL-LJ$. Two closed-form divergence checks exercise the Cartesian vertical and cylindrical radial directions. On each sampled radial element join, the independent residual is the mean of the left and right strong traces. The individual RMS values and half-jump RMS are reported alongside it.

Both operators use the analytic source and the reference's nodal conformal factor. All comparisons and decompositions use a common normalized weight $r(R+r\cos\theta)\psi_{\rm hybrid}^{6}$ on the original audit nodes. The first row is the first interior radial node. The inner band uses all interior radii through $r=0.10$.

At the final angular doubling, both operators' vector differences have observed orders 1.999 to 2.000. The extrapolated correction to the frozen vector is at most 0.025% of its estimated floor RMS. The operator gap is 136 to 8,545 times the independent residual at the finest measured angles across both regions.

A separate [radial control](results/radial_control.csv) holds the angles at $4N$ and compares $4N$ and $8N$ radial intervals. Across the four inner-band grids the frozen vector changes by $3.02\times10^{-14}$ to $1.22\times10^{-9}$, while the independent strong residual changes by $1.26\times10^{-7}$ to $1.36\times10^{-4}$. The left/right derivative jumps also diminish with radial refinement. This makes the smaller independent floor sensitive to the radial reconstruction. The frozen floor is much larger and stable under the measured angular correction.

The observed slopes and extrapolations are finite-resolution evidence. The independent operator evaluates the strong residual of a piecewise reconstruction with a trace convention at element joins. The comparison leaves open how much of its small residual floor comes from radial approximation, trace averaging, or angular effects below the resolved range. The operator gap measures the combined effect of frozen differentiation on these fields. The decomposition cannot localize that gap to a particular derivative or certify a general asymptotic bound.

## Reproduction and hashes

Run from the repository root with Python 3.12.14. The first command below installs the pinned numerical dependencies. Run the solves serially to limit memory. The half-density radial controls reuse already generated solves with the same absolute angular and radial counts.

~~~bash
python -m pip install numpy==2.3.5 scipy==1.17.0 pymetis==2025.2.2 mpmath==1.3.0
export OPENBLAS_NUM_THREADS=1
work=$(mktemp -d)
python research/run43_hybrid/physical.py "$work/hybrid"
python research/run43_asymptotic/solve_levels.py "$work/levels" --factors 2 4 8
python research/run43_asymptotic/solve_levels.py "$work/levels" --factors 16 --grids 8 16 32
python research/run43_asymptotic/solve_levels.py "$work/levels" --factors 32 64 --grids 8 16
python research/run43_asymptotic/solve_levels.py "$work/levels" --factors 32 --grids 32
python research/run43_asymptotic/measure.py "$work/levels" "$work/hybrid" "$work/results"
diff -r research/run43_asymptotic/results "$work/results"
sha256sum "$work/hybrid"/fields_*.npz "$work/hybrid/independent-audit.json"
~~~

The measurement command invokes the original acceptance runner and expects its exit code 1 for the archived 9/12 result. Its [compact output](results/hybrid-audit.json) matches the archive byte for byte. The auditor Git blob is `5e4e54e1e1d84b785c4e66eac9b4d7fffdc43e22`. The SHA-256 of the full regenerated audit JSON, including grid rows, is `6c10d04f1ffbb9006b9544f8c2bb5669218a614f99d5e608db0d4fd6c4207de1`. The [hash manifest](results/provenance.json) lists all four hybrid field hashes, archived input and code hashes, and the generated result hashes.

The environment had an 8 GiB memory cgroup and a two-CPU quota. The completed 512-angle, 512-radial run approached the memory ceiling, with sampled process RSS of about 7.7 GiB. On the $N=64$ grid, the $16N$ attempt (1,024 angles, 512 radial intervals) failed while assembling the sparse vector regularizer. With an 8,000,000 KiB process address-space cap, NumPy was unable to allocate a 120 MiB temporary. The failure happened before factorization and produced no field or residual. The remaining angular sweeps stop at the measured levels above.
